# VACINA 01 — QA GATE V1

## Gate 0 — Fonte

- [ ] Prompt Mestre vigente lido
- [ ] Cockpit vigente lido
- [ ] Conflitos reconciliados
- [ ] Versões antigas marcadas como históricas/superseded
- [ ] Asset e referência visual corretos

Falha em qualquer item: BLOQUEAR.

## Gate 1 — Técnico

- [ ] Arquivo abre
- [ ] Dimensão e proporção corretas
- [ ] Texto dentro da área segura
- [ ] Nitidez e exportação verificadas
- [ ] Nome, versão e hash registrados

## Gate 2 — Visual

- [ ] Rosé Editorial preservado
- [ ] Sem verde/verde-oliva
- [ ] Hook é o maior destaque
- [ ] Espaçamento, simetria e hierarquia revisados
- [ ] Layout agradável em tela cheia e miniatura
- [ ] Pet sem deformações, halos ou aparência plástica
- [ ] Foto da Larissa, se usada, preservada sem alteração de características

## Gate 3 — Editorial

- [ ] Uma ideia principal
- [ ] Texto legível
- [ ] Português revisado
- [ ] Legenda complementa a arte
- [ ] CTA natural
- [ ] Sem repetição integral do carrossel

## Gate 4 — Clínico e direitos

- [ ] Claims identificados
- [ ] Fonte adequada quando necessário
- [ ] Validação da Larissa separada
- [ ] Consentimentos e proveniência registrados
- [ ] Sem paciente, depoimento ou resultado inventado

## Gate 5 — Estado

- [ ] Arte, copy, clínica e publicação separados
- [ ] Aprovação ligada à versão exata
- [ ] Publicação não presumida
- [ ] Memória, Sheet e manifest atualizados
- [ ] Rollback possível

Resultado permitido: CANDIDATA, APROVADA, VALIDADA, PUBLICADA CONFIRMADA ou BLOQUEADA. Nunca promover estado sem evidência.
